# Настройка переменных окружения для Vercel

После загрузки проекта на GitHub и подключения к Vercel, необходимо настроить переменные окружения:

## Важно!

После добавления переменных окружения в Vercel необходимо сделать новый деплой!
Vercel не применяет новые переменные к существующим деплоям автоматически.

## В настройках проекта Vercel

1. Перейдите в настройки проекта на vercel.com
2. Откройте раздел "Environment Variables"
3. Добавьте следующие переменные:

### Для фронтенда (Vite)
- `VITE_TELEGRAM_BOT_TOKEN` = `8035311656:AAFB8nrpINRSaREmNRtevET2iOjREohVgGs`
- `VITE_TELEGRAM_CHAT_ID` = `592052544`

### Для серверной части (API)
- `NODE_ENV` = `production`
- `BOT_TOKEN` = `8035311656:AAFB8nrpINRSaREmNRtevET2iOjREohVgGs`
- `CHAT_ID` = `592052544`
- `ALLOWED_ORIGINS` = `*`

## Локальная разработка

Для локальной разработки создайте файл `.env` в корне проекта со следующим содержимым:

```
VITE_TELEGRAM_BOT_TOKEN=8035311656:AAFB8nrpINRSaREmNRtevET2iOjREohVgGs
VITE_TELEGRAM_CHAT_ID=592052544
```

## Безопасность

Файл `.env` добавлен в `.gitignore` и не будет загружен в репозиторий.
Переменные с префиксом `VITE_` будут доступны в браузере, остальные только на сервере.
