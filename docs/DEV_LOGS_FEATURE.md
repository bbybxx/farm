# Dev Logs Feature

## Описание
Добавлена внутренняя страница логов разработки для отслеживания всех обновлений и изменений приложения.

## Изменения

### Новые файлы:
- `src/components/DevLogs.jsx` - Компонент модального окна с логами разработки
- `src/components/DevLogs.css` - Стили для страницы логов

### Измененные файлы:
- `src/app/App.jsx`:
  - Добавлен импорт компонента `DevLogs`
  - Добавлено состояние `isDevLogsOpen` для управления модальным окном
  - Заменена кнопка Reddit на кнопку Dev Logs с иконкой документа
  - Добавлен компонент DevLogs в конец разметки

- `src/app/app.css`:
  - Добавлены стили для обеспечения отображения текста в одну строку
  - Добавлена поддержка SVG иконок в социальных ссылках

## Функциональность

### Кнопка Dev Logs:
- Располагается в разделе Settings → Updates
- Открывает модальное окно со списком логов разработки
- Использует SVG иконку документа вместо внешнего изображения
- Текст кнопки всегда остается в одной строке

### Страница логов:
- Отображает хронологический список всех обновлений (от новых к старым)
- Каждая запись содержит:
  - Дату обновления
  - Заголовок
  - Описание изменений
- Модальное окно с плавной анимацией появления/исчезновения
- Адаптивный дизайн, соответствующий общему стилю приложения

## Добавление новых логов

Чтобы добавить новую запись в логи, отредактируйте файл `src/components/DevLogs.jsx`:

```jsx
const logs = [
  {
    id: 4, // следующий уникальный ID
    date: '2025-11-06', // дата в формате YYYY-MM-DD
    title: 'Название обновления',
    content: 'Описание того, что было изменено или добавлено.'
  },
  // ... существующие записи
]
```

## Стилизация

Логи используют тот же glass-morphism стиль, что и остальное приложение:
- Полупрозрачный фон
- Плавные переходы при наведении
- Акцентный цвет для дат
- Читаемая типографика

## Примечания
- Внешняя ссылка на Reddit была заменена на внутреннюю страницу логов
- Это обеспечивает лучший пользовательский опыт и держит пользователей в приложении
- Логи легко обновлять без необходимости изменения внешних ресурсов
