# Жёсткие правила для всех шагов (НЕ НАРУШАТЬ)

## Запрещено
1. **Трогать `src/app/App.jsx`** — НИКАКИХ изменений в этом файле. Ни строчки.
2. **Трогать `src/components/AppHeader.jsx`** — НИКАКИХ изменений.
3. **Трогать `src/components/Sidebar/SettingsTab.jsx`** — НИКАКИХ изменений (кроме импорта `useEconomy` и добавления секции "Plugins" с чекбоксом, если это явно разрешено в шаге 3).
4. **Трогать существующие хуки** (`useCraft`, `useUIState`, `useSettings`) — не менять их логику.
5. **Использовать `craftChain`** в экономическом режиме — только `economyChain`.

## Разрешено
1. **Создавать новые файлы** только в папке `src/plugins/` (для экономики — `src/plugins/economy/`).
2. **Создавать новые компоненты** внутри `src/plugins/economy/components/`.
3. **Использовать существующие хуки** (например, `useSettings`) только для чтения (не менять их).
4. **В `App.jsx` добавить только одну строчку** — `<PluginsRenderer />` (и только если это явно разрешено в шаге 9). Эту строчку добавляет **пользователь вручную**, а не агент.
5. **PluginsRenderer** (`src/plugins/index.jsx`) — единая точка входа для всех плагинов. Плагины сами решают, показываться или нет.

## Проверка перед коммитом
- Запусти `npm run build` — должно собираться без ошибок.
- Проверь, что обычный режим (без экономики) работает как раньше.
- Проверь, что экономика включается через чекбокс в настройках (секция "Plugins").
- Если что-то сломалось — откатывай изменения и переделывай.
