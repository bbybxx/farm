- ID: 8035311656

## Шаги для получения Chat ID:

### 1. Найдите бота в Telegram
Перейдите по ссылке: https://t.me/ofeodicisiewisixbot
Или найдите бота по username: `@ofeodicisiewisixbot`

### 2. Запустите диалог с ботом
Нажмите кнопку **"Start"** или отправьте команду `/start`

### 3. Отправьте любое сообщение
Например: "Привет" или "Тест"

### 4. Получите Chat ID
После отправки сообщения, запустите в терминале:
```bash
cd server
node test-bot.js
```

Скрипт покажет ваш Chat ID, например:
```
Use this Chat ID in your .env file:
CHAT_ID=123456789
```

### 5. Обновите .env файл
Замените `YOUR_CHAT_ID_HERE` на полученный Chat ID в файле `server/.env`:
```env
CHAT_ID=123456789
```

### 6. Перезапустите сервер
```bash
cd server
npm run dev
```

## Тестирование

После настройки Chat ID:

1. Откройте приложение: http://localhost:5173/
2. Перейдите в Settings → Bug Report
3. Отправьте тестовое сообщение
4. Проверьте, что сообщение пришло в Telegram

## Группы и каналы

Бот также может отправлять сообщения в группы:

1. Добавьте бота в группу
2. Дайте боту права на отправку сообщений
3. Отправьте сообщение в группе  
4. Получите Chat ID группы через `node test-bot.js`
5. Используйте Chat ID группы в `.env`
